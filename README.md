## What It Does

Takes 50 structured screenplay `.txt` files for *I Married a Broken Soldier. He was a Duke* and automatically identifies the best 20–60 second promotional clips — ranked by hook strength, cliffhanger quality, standalone clarity, and emotional intensity.

**Output:** 673 ranked promo windows with timestamps, scores, and explanations — ready for a human video editor.

---

## Quick Start

### Option A — Offline (no API key needed, runs in ~6 seconds)
```powershell
pip install -r requirements.txt
python generate_outputs.py
```

### Option B — Gemini 3.5 Flash (full LLM scoring)
```powershell
pip install -r requirements.txt
# Paste your Gemini API key in .env
python main.py
```

### Option C — API spot-check on 2 episodes only
```powershell
python quick_test.py   # scores Ep 1 & 2 via Gemini in ~3 minutes
```

## Pipeline

```
50 × .txt scripts
      │
  parser.py        Regex extracts timed events: DIALOGUE, ACTION, CAMERA, SOUND_FX
      ↓
  extractor.py     Sliding 20–60s windows (5s step) → 9,728 candidates
                   + cross-episode stitching → 1,604 extra candidates
      ↓
  local_scorer.py  Rule-based scoring — hook phrases, emotion tags, cliffhanger
  OR scorer.py     Gemini 3.5 Flash scoring — LLM evaluates same 4 dimensions
      ↓
  main.py          Composite score → 70% IoU dedup → rank → 3 output files
```

**Composite score formula:**
```
score = 0.35 × hook + 0.35 × cliffhanger + 0.20 × standalone + 0.10 × emotion
```

## Scoring Dimensions

| Dimension | Weight | How scored (local) | How scored (Gemini) |
|-----------|--------|--------------------|---------------------|
| **Hook** | 35% | Power phrases + emotion tags in first 3s | LLM rates what a TikTok scroller would see first |
| **Cliffhanger** | 35% | Question marks + unresolved phrases in last 5s | LLM rates whether viewer *needs* to know what happens next |
| **Standalone** | 20% | Named characters + scene words + dialogue count | LLM rates if a new viewer understands the stakes |
| **Emotion** | 10% | Screenplay emotion tags (Heartbroken, Outraged…) | LLM rates overall emotional charge |

## Known Limitations

- **Daily API quota**: Free tier has a daily cap. If you hit 429, wait for midnight PT reset and run `quick_test.py` first.
- **Text-only**: Visual hooks (slaps, gasps without dialogue) score lower than they should. Audio/video embeddings would fix this.
- **English only**: Hindi/Tamil shows need language-specific prompt tuning.
- **No video verification**: Timestamps are from scripts — assumed to match actual video.
